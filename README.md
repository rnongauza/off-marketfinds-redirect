# off-marketfinds-redirect

Old address off-marketfinds.com now lives at **bridgeplaceshowcase.com**.
This GitHub Pages site sends every old link to the same path on the new domain
(for example `off-marketfinds.com/go/4418k` → `bridgeplaceshowcase.com/go/4418k`).
`404.html` handles every path; `index.html` handles the home page.
